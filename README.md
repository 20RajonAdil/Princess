# From Adil to Princess

A small, animated page for Princess Mia, ruler of Kepler-23.

- Animated SVG planet, self-drawing crown and cat moon
- Starfield with shooting stars, soft colour fields, cursor sparkle trail
- Poem generator with typewriter effect, rotating royal titles, cat rain and sparkle bursts
- Poems and titles are checked against a blocked-word list in `script.js` before they can appear
- Respects reduced-motion settings, works on phones, keyboard friendly (`C` for cat rain, `S` for sparkles)

No build step: open `index.html` or host the folder (for example GitHub Pages).
